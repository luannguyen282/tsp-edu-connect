# TSPEC Project Context

TSPEC is a center-first, multi-tenant education-center operations product.

Canonical product authority: `docs/product/TSPEC_BUSINESS_RULES_MASTER_V6.md`.

UX/screen reference: `docs/reference/tspec-prototype-v7.html` and `docs/product/UI_SURFACE_MAP.md`.

Baseline non-goals:

- public self-signup;
- invitation activation;
- accountant/cashier workspaces;
- payroll;
- S3/MinIO;
- SMS/email providers;
- Keycloak;
- Redis/job infrastructure;
- microservices;
- deep automated/unit testing.

Implementation goal: deliver complete basic flows for the approved business rules and designed screens using a small modular monolith.
