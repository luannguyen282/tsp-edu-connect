# General Rules

- Execute the active plan; do not invent product scope.
- Use task dependencies as the execution order.
- Prefer complete vertical slices over generic abstractions.
- Reuse existing patterns before adding dependencies.
- Keep source changes scoped to the active task.
- Update task evidence only after the declared validation passes.
- If runtime is unavailable, mark the task blocked/deferred honestly and continue only with independent work.
